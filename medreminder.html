Undergraduate Project - Universitas Airlangga

MedReminder

Project Overview

This project is the final assignment for the Computer Programming course. The final project involved creating an application using the Python programming language. The program was developed by a team of two members using Anaconda software.

The MedReminder Application serves as a reminder for medication schedules and health check-ups.
